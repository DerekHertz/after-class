- 2026-11-03, retro 3 (counts from the verifier reports in the orchestrator session, not kept in the repo) (merged #28, #30, #31, #32; #29 dropped by Derek; 3 of 5 failed their first review). Failures by class:
  1. A guard checked a path that was not normalized first: #29 `cleanup.sh` was bypassed by `..`, then by a trailing slash. Two rounds, then dropped. Cause: the guard matched the raw string. Rule for any future path guard: normalize once (strip trailing slashes, reject `..`, resolve symlinks), then run every check and the action on that one value.
  2. An assumption the code did not enforce: #32 relied on "a saved review is final" while the save route and the turn route accepted a save before the end and a turn after it. Fixed in code (409 on an unended save, `turn_failed` on a turn after the end), with a test for each.
  3. A docs edit left a stale line: #30 (the plan intro still named the dropped skill). Process slip, not a code class; a docs PR that drops a feature greps for the feature's name before it opens.
  Process fix: after a push, `git rev-parse origin/<branch>` must equal the local head. A detached HEAD made one fix push silently not land, and the verifier read the old head.
  Repeats of retro 1 classes: none. Class 2 here is new (an unenforced assumption), and the M10 resend test caught the one retro-1 repeat (a retry that was not answered from the first attempt); #32 fixed it.
- 2026-11-03, retro 4 (counts from the verifier reports in the orchestrator session, not kept in the repo) (merged #34, #35, #36; 1 of 3 failed its first review). Failure: #36 the zero-ads bar printed PASS while a leaked ad span or passage existed, because only frames in the ad window were candidates. Class: a check that passes on silence (an input it never looked at). Fixed in code, not wording: with an ad record, every frame, passage and watched interval in the window is a candidate and needs Derek's check; an unchecked candidate or no ad record is NOT MEASURED, never PASS (a bundle that reproduces the failure is now a test). No repeat of retro 1 to 3 classes. The #36 gap was found by the verifier building its own bundle, not by the worker's tests, so the verifier brief now says to reproduce with an input of their own before reading the PR's tests.
